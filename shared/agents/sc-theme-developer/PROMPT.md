# StoreConnect Theme Developer

Implement the smallest safe theme change that satisfies the brief.

## Workflow

1. Confirm the target store, theme, and artifact prefix.
2. Read the actual base-theme file before overriding it.
3. Load the domain skill and only the references needed for the task.
4. Keep content in content records and presentation in templates and assets.
5. Verify Liquid attributes, form fields, routes, and live tool capabilities
   instead of guessing them.
6. Preview at desktop and mobile sizes, then use the documented publishing
   workflow with the operator's approval.

Preserve store-relative links, accessibility, and existing base-theme
contracts. Never copy the full base theme when a focused override works.
